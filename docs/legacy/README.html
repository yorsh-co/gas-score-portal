# 📊 Publicação de Notas Sistema completo para **importação automática de Google Forms**, sincronização de respostas e **publicação de notas via WebApp**, construído inteiramente com **Google Apps Script**, integrado a **Google Sheets**, **Google Drive** e **Google Forms**. --- ## 🎯 Visão Geral **Publicação de Notas** é um sistema automatizado que: * 🔎 Localiza Google Forms em uma pasta do Drive * 🔗 Vincula os Forms a uma planilha central * 📥 Sincroniza automaticamente as respostas * 🧮 Calcula pontuações de quizzes * 💾 Mantém histórico incremental com cursor inteligente * 🌐 Publica um WebApp para visualização externa das notas * 🔁 Executa sincronização periódica via acionadores (triggers) O sistema foi projetado para operar de forma robusta e autônoma, com controle administrativo diretamente pela interface da planilha. --- # 🏗 Arquitetura do Sistema O projeto é organizado em camadas claras: ``` domain/ → Modelos de domínio (LinkedForm) infra/ → Integrações com Drive, Forms, Sheets e Apps Script API app/ → Serviços principais do sistema ui/ → Menu e handlers da interface triggers/ → Acionadores automáticos webapp/ → Aplicativo web utils/ → Utilidades ``` --- ## 1️⃣ Integração com Google Forms Responsável por: * Buscar Forms no Drive * Filtrar por título ou conteúdo * Ignorar URLs excluídas * Calcular pontuação máxima de quizzes * Tratar múltiplas respostas por usuário Principais componentes: * `FormsImporter` * `GDrive` * `GForms` * `LinkedForm` * `FormsSheet` --- ## 2️⃣ Sincronização de Notas O motor de sincronização: * Usa `FormsCursor` para processamento incremental * Evita reprocessamento desnecessário * Detecta: * Novas notas * Notas alteradas * Usa `ExecutionLock` para evitar concorrência * Continua automaticamente se atingir limite de tempo Principal classe: * `RespondentScoreSynchronizer` Execução automática: * `timedSyncScores` * `continueSyncScores` --- ## 3️⃣ Estrutura da Planilha A planilha contém: ### 🟪 Aba: Forms Lista os Forms vinculados: * URL * Título * Status * Timestamp da última sincronização ### 💯 Aba: Notas * Cada coluna representa um Form * Cada linha representa um participante * Linha superior: URLs dos Forms * Linha de pontuação máxima * Dados normalizados por e-mail ### ⚙️ Aba: Config Configuração central do sistema. --- # ⚙️ Configuração A aba **⚙️ Config** armazena todas as configurações persistidas via `PropertiesService`. ### global | Campo | Descrição | | ---------------- | --------------------- | | localeIdentifier | Localidade do sistema | ### gForms | Campo | Descrição | | ------------- | ----------------------- | | excludedUrls | Lista de URLs ignoradas | | titleQuery | Filtro por título | | fullTextQuery | Filtro por conteúdo | ### gDrive | Campo | Descrição | | --------------- | ---------------------------------- | | parentFolderUrl | Pasta onde os Forms serão buscados | ### appsScript | Campo | Descrição | | ------------- | -------------------------- | | authStatus | Status da autorização | | versionNumber | Versão atual do deployment | | deploymentId | ID do deployment | | webappUrl | URL do WebApp | | webappTitle | Título exibido | | faviconUrl | Favicon | | entryRoute | Rota inicial do WebApp | --- # 🚀 Instalação ## 1️⃣ Preparar a Planilha 1. Copiar estrutura de abas: * 🟪 Forms * 💯 Notas * ⚙️ Config 2. Verificar o preenchimento dos campos na aba "⚙️ Config" ## 2️⃣ Instalar o Script * Abrir o menu "🔶 Sistema de Notas" * Clicar em "⚙️ Configurações" > "💽 Instalar o Script" * Autorizar as permissões * As configurações serão salvas * Os acionadores serão instalados * O aplicativo web será publicado * Salvar o URL do WebApp ## 3️⃣ Configurar Na aba ⚙️ Config: * Definir pasta do Drive * Definir filtros de Forms * Salvar configurações pelo menu --- # 🔐 Autorização O sistema utiliza a **Apps Script API** para criar versões e deployments. Escopos necessários: * script.projects * script.deployments Se necessário, o sistema solicitará autorização e atualizará o status na aba Config. --- # 🔁 Funcionamento Automático A cada 30 minutos: 1. Busca novos Forms 2. Atualiza Forms existentes 3. Processa respostas 4. Atualiza notas 5. Continua automaticamente se necessário Sistema resiliente a: * Timeouts * Interrupções * Execuções parciais --- # 🧠 Estratégias Técnicas Utilizadas * Cursor incremental persistido * Lock de execução * Atualização diferencial de notas * Continuação automática via trigger * Proteção de células críticas * Versionamento automático de WebApp --- # 📦 Deploy do WebApp Gerenciado por: * `WebAppDeployer` * `AppsScriptApi` Permite: * Criar deployment * Atualizar deployment * Limpar deployments antigos * Resetar completamente A URL final pode incluir rota: ``` ?route= ``` --- # 🛠 Desenvolvimento ## Versionamento Segue princípios de versionamento semântico.
